Didactics & Concept

O Ciclo MLOps do Agente Hermes

Bem-vindo ao Hermes Lab! Este ambiente foi projetado para ensinar de forma interativa e guiada como a orquestração e a governança de IA acontecem antes de colocarmos agentes autônomos em produção.

Diferente de arquiteturas ingênuas, no MLOps de produção as ações do agente dependem de evidências calibradas, contratos explícitos e auditoria determinística.

O Fluxo de Trabalho do Lab

1. Evaluation Testes SxS ou RAG geram dados empíricos de qualidade.
2. Run A execução do teste cria um log de logs estruturado (Contexto JSON).
3. Hermes Lê O Hermes Agent ingere o JSON seguindo contratos formais sem efeitos colaterais.
4. Diagnóstico O Hermes gera recomendações e pontuações de confiança explicáveis.

Da Confiança (Second Brain) à Ação (Atlas OS)

A filosofia do laboratório divide o ciclo em duas pontas fundamentais:
• Second Brain: É onde você está agora. O objetivo é testar, avaliar, rodar inferências paralelas e calibrar rubricas. O Second Brain constrói e treina a confiança.
• Atlas OS: É a futura camada operacional. Ele consome as rubricas e os pesos validados aqui para executar ações no mundo real de forma robusta e com governança estrita. O Atlas OS gasta a confiança.
• Hermes: É o agente regulador. Ele observa os dados de rodada (Observe) e aconselha o cientista de dados (Advise), prevenindo alucinações e desvios de contratos.

Instruções de Estudo:

  1. Navegue até a aba 2. Hermes Advisor para experimentar diagnósticos reais usando templates estruturados.
  2. Altere os valores de DPO ou RAG e observe como as regras de negócio do Hermes reagem instantaneamente.
  3. Consulte o status do seu servidor local do Ollama no painel lateral para garantir que seus modelos locais estejam ativos.

Estrutura do Contrato

Guia de Formatação JSON

O Hermes lê o contexto fornecido pelo run e valida os dados de acordo com regras determinísticas.

current_models Define os modelos usados na geração e como juiz (judge). O Hermes alerta se o mesmo modelo atuar em ambas as pontas (viés de auto-avaliação).
rubric Informa a quantidade de regras e dimensões associadas. Poucas regras ativam alertas de baixa fidelidade do teste.
result Contém a margem de diferença obtida entre a resposta escolhida e a rejeitada no SxS.
current_thresholds Os limites estatísticos do experimento. Se a margem estiver abaixo do threshold, o Hermes sinaliza inconsistência.
